# Interface direction

## Baseline surfaces

Smallest set of pages and states that expose visual needs.

## Components

| Need | Component | Keyboard behavior | Notes |
| --- | --- | --- | --- |

## Token roles

Typography, spacing, color, density — roles, not page-specific values.

## Interaction states

Default, hover, focus, active, selected, disabled, loading, error, destructive.

## Accessibility notes

Focus order, contrast, zoom, reduced motion, screen-reader announcements.

## Handoff for Finn

Component behavior and acceptance criteria, not only images.
